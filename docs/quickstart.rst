Quickstart
==========

The example API is intentionally small. This code works after installing the
checkout and must be updated when the real public API replaces it.

.. code-block:: python

   from project_name import greet

   print(greet())
   # hello

The starter notebook runs the same example and contains placeholders for the
PoC question, inputs, agreed approach, results, and limitations. It does not
prescribe a scientific method or success metric.
